# Titanic Survival Analysis

## Objective
Analyze the Titanic dataset and identify factors that influenced passenger survival.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed
- Data Cleaning
- Missing Value Handling
- Survival Analysis by Gender
- Survival Analysis by Passenger Class
- Survival Analysis by Age Group
- Data Visualization

## Key Findings
- Female passengers had a significantly higher survival rate.
- First-class passengers had the highest chance of survival.
- Children showed better survival rates than senior passengers.

## Dataset
Titanic Dataset from Kaggle.
